# ตอนที่ 32 การศรัทธาในคัมภีร์อัตเตารอต (โตราห์ ของยิว)
- id: pgGnDJXgSYo · ชุด: 2020 · ตอน: 32 · ความยาว: 102 นาที · ผู้บรรยาย: อาจารย์ (ผู้ดำเนินรายการเปิดหัวข้อ ~19 นาทีแรก แล้วส่งต่อให้อาจารย์ผู้บรรยายหลัก) — รายการ "เสวนาปัญหาคาใจ" ทีวี (ชื่อสถานีตามซับไม่ชัด)
- สรุปคลิป: ช่วงแรก (0–19 นาที) ผู้ดำเนินรายการเทศนาเรื่องอีมานที่ขึ้นลง มีช่วงกระตือรือร้นและช่วงซบเซา และเตือนนักดะอฺวะฮ์ไม่ให้ "เปลี่ยนสูตร" ตอนเบื่อหน่าย · ช่วงที่สอง (19–39 นาที) อาจารย์แวะพูดเรื่องสังคม: กิจกรรมรับน้องในมหาวิทยาลัย การแจกถุงยาง การส่งเสริมให้แต่งงานเร็ว และหลักการ "สิ่งที่นำสู่บาป ก็เป็นบาป" · ช่วงที่สาม (39 นาทีจนจบ) เข้าเนื้อหาหลัก: คัมภีร์ 5 เล่มที่ถูกระบุชื่อ, คัมภีร์เตารอตของนบีมูซา, ภาษาของเตารอต/อินญีล/ซะบูร, ความสัมพันธ์ระหว่างยิว-คริสต์-อิสลาม, ฮุก่มแต่งงานกับหญิงอะฮ์ลุลกิตาบ, ระบบสายรายงานที่คัมภีร์ของเขาไม่มี, และปิดท้ายด้วยเรื่อง "ตะห์รีฟ" (การบิดเบือน) พร้อม 2 ทัศนะของอุละมาอ์และทัศนะที่อาจารย์เลือก
- คุณภาพซับ: แย่ — ASR เพี้ยนหนักมาก คำอาหรับผิดแทบทั้งหมด ชื่อคน/ชื่อหนังสือ/เลขเล่ม-หน้าเชื่อไม่ได้ · ตัวบทอายะฮ์และหะดีษที่อาจารย์อ่านออกมาเป็นภาษาอาหรับกลายเป็นคำไทยมั่วเกือบ 100% · ช่วงที่แย่ที่สุดคือ [004:04]–[006:05], [083:47]–[092:52] และ [094:53]–[099:56] (ตัวบทอาหรับยาวติดกันหลายบรรทัด) · ชื่อผู้บรรยายและชื่อสถานีอ่านไม่ออก · คำที่อาจารย์พูดเป็นภาษาไทยยังพออ่านได้และเป็นฐานหลักของการ์ดชุดนี้

### C02 · หะดีษ: ทุกการงานมีช่วงกระตือรือร้นและช่วงซบเซา
- หมวด: อีมาน-ความหมาย/เพิ่มลด/กิ่งก้าน
- ระดับ: แก่น — เป็นหลักฐานตั้งต้นของทั้งช่วงแรกของคลิป และเป็นสิ่งที่มุสลิมใหม่ต้องรู้ล่วงหน้าว่าจะเจอ
- สาระ:
  - อาจารย์บอกว่าสิ่งใดที่นบีเตือนว่าจะเกิดกับเรา มันจะเกิดแน่ เลี่ยงไม่ได้ เราจึงไม่ใช่แค่อ่านหะดีษเฉยๆ แต่ต้องเตรียมการรับมือ
  - หะดีษบทนี้บอกว่า ทุกๆ การงาน ทุกๆ อะมัล ทุกๆ อิบาดะฮ์ จะมีสภาวะของการกระตือรือร้น
  - และสภาวะที่กระตือรือร้นนั้น เดี๋ยวก็จะตามมาด้วยสภาวะซบเซา เบื่อหน่าย ไม่อยากทำอะไรต่อ
  - อาจารย์บอกเองว่า "อันแบบนี้ไม่เข้าใจหรอก ผมเองอ่านแล้วแปลความหมายเฉยๆ ก็ไม่เข้าใจ ต้องไปดูอุละมาอ์มาอธิบาย"

- หลักฐาน:

- อุปมา/ตัวอย่าง: -
- ศัพท์: (อาจารย์ออกเสียงตามซับว่า "ชิรเราะฮ์/ฟัตเราะฮ์" ไม่ชัด) — ช่วงกระตือรือร้น = ช่วง Active อยากทำความดี ; ช่วงซบเซา = ช่วงเบื่อหน่ายไม่อยากทำอะไร

### C03 · ท่อนตัดสินของหะดีษ: ซบเซาแล้วยังอยู่ในสุนนะฮ์ = ได้ทางนำ ออกนอก = พินาศ
- หมวด: อีมาน-ความหมาย/เพิ่มลด/กิ่งก้าน / กลุ่มหลงผิด
- ระดับ: แก่น — เป็นจุดชี้ขาดของหะดีษ และเป็นเกณฑ์วัดตัวเองในช่วงอ่อนแอ
- สาระ:
  - ท่อนต่อของหะดีษบอกว่า ใครก็แล้วแต่ที่ช่วงเวลากระตือรือร้นของเขา เขาใช้มันไปในแนวทางที่ถูกต้อง ตามสุนนะฮ์ของนบี เขาจะได้รับชัยชนะ
  - และใครก็แล้วแต่ที่ช่วงเวลาเบื่อหน่ายของเขา ทำให้เขาออกห่างจากแนวทางของนบี เขาจะได้รับความพินาศ
  - อาจารย์เน้นว่า ตัวชี้ขาดไม่ใช่ว่าเราขยันหรือขี้เกียจ แต่คือ "ตอนขยันเราขยันไปทางไหน" และ "ตอนเบื่อเราเบื่อจนหลุดออกไปหรือเปล่า"

- หลักฐาน:
  - [หะดีษ] ที่ได้ยิน: ท่อนต่อของหะดีษเลขที่ 2151 เดียวกับ C02 — ตามซับ "ฟังมั่งจ้าน่ะประมาณก็น่าเชื่อเราโตหู่นะครับ ...ขอเช็คประตูวีล่าสุดนาที..." · น่าจะเป็น: ไม่ทราบ · ใจความ (ตามที่อาจารย์แปล): "ผู้ใดที่ช่วงซบเซาของเขายังอยู่ในสุนนะฮ์ของฉัน เขาได้รับทางนำแล้ว และผู้ใดที่ช่วงซบเซาของเขาไปสู่อย่างอื่นจากนั้น เขาก็พินาศ"

### C04 · ช่วงกระตือรือร้นต้องอยู่ในกรอบ อย่าสุดโต่ง — เรื่องเศาะฮาบะฮ์ 3 คน
- หมวด: อื่นๆ (มารยาทการทำอิบาดะฮ์) / อีมาน-ความหมาย/เพิ่มลด/กิ่งก้าน
- ระดับ: เสริม — เป็นเรื่องเล่าประกอบที่ทำให้มุสลิมใหม่เห็นขอบเขตของความขยัน
- สาระ:
  - อาจารย์บอกว่าช่วงที่อยากทำดี ให้รีบตักตวง ทำให้สุดๆ ไปเลย แต่ต้องอยู่ในกฎเกณฑ์ของศาสนา
  - ไม่ใช่ตักตวงจนออกไปสุดโต่ง
  - แล้วยกเรื่องในสมัยนบี มีเศาะฮาบะฮ์จำนวนหนึ่ง (ตามซับดูเหมือน 3 คน) ที่ตั้งใจว่า คนหนึ่งจะถือศีลอดตลอดปี คนหนึ่งจะไม่แต่งงาน อีกคนจะไม่กินเนื้อสัตว์ (ท่อนนี้ซับไม่ชัด)
  - อาจารย์เรียกว่านี่คือ "อยากทำดีจนตักตวงสุดๆ แต่กลายเป็นสุดโต่ง" และนบีต้องตักเตือน
- ทัศนะที่เลือก: -
- หลักฐาน:
  - [หะดีษ] ที่ได้ยิน: "ในสมัยท่านนบีมีสอบบ้านอยู่จำนวนหนึ่งที่มาหารบี ระบบว่าฉันเนื้อหรือชุดอดใหม่ๆ ...อีกคนจะไม่แต่งงาน อีกคนนึงไม่กินเนื้อสัตว์" (ไม่ระบุที่มา) · น่าจะเป็น: ไม่ทราบ (อาจารย์เล่าเป็นเรื่อง ไม่ได้อ้างเล่ม) · ใจความ: เศาะฮาบะฮ์กลุ่มหนึ่งตั้งปณิธานทำอิบาดะฮ์เกินขอบเขต นบีจึงตักเตือน
- อุปมา/ตัวอย่าง: เศาะฮาบะฮ์ที่ตั้งใจถือศีลอดตลอดปี / ไม่แต่งงาน / ไม่กินเนื้อสัตว์
- ศัพท์: สุดโต่ง = ทำเกินกรอบที่ศาสนากำหนด แม้จะทำด้วยเจตนาดี
- ช่วง: [007:06]

### C05 · ช่วงซบเซาต้องประคองตัว: สุนัตลดได้ ฟัรฎูห้ามทิ้ง
- หมวด: อีมาน-ความหมาย/เพิ่มลด/กิ่งก้าน / ผลของศรัทธาต่อชีวิต
- ระดับ: แก่น — เป็นคำแนะนำปฏิบัติที่มุสลิมใหม่ใช้ได้ตรงๆ เวลาอีมานตก
- สาระ:
  - ช่วงเบื่อหน่ายต้องประคองตัวเอง อย่าให้เลยเถิด
  - ตอนขยันเราละหมาดสุนัตเยอะ ตอนเบื่อ สุนัตอาจลดลงได้ แต่ฟัรฎูต้องอยู่ครบ
  - เส้นตายคือ ต้องไม่ทิ้งฟัรฎู และต้องไม่ล่วงล้ำไปสู่บาป โดยเฉพาะบาปที่อาจารย์เรียกว่า "ด้าน 2" หรือ "ด้าน 3"
- ทัศนะที่เลือก: -
- หลักฐาน: -
- อุปมา/ตัวอย่าง: คนที่เคยละหมาดสุนัตมากมาย พอเบื่อก็ลดสุนัตลงได้ แต่ฟัรฎูยังครบ
- ศัพท์: ฟัรฎู = ที่ต้องทำ ; สุนัต = ที่ทำแล้วได้ผลบุญเพิ่ม

### C06 · ระบบ "บาปด้าน 1 / ด้าน 2 / ด้าน 3" ที่อาจารย์ใช้ตลอดคลิป
- หมวด: อื่นๆ (ศัพท์ประจำตัวผู้บรรยาย) / ชิริก
- ระดับ: เสริม — ไม่ใช่หลักศรัทธาเอง แต่จำเป็นต่อการอ่านการ์ดอื่นในคลิปนี้ให้รู้เรื่อง
- สาระ:
  - อาจารย์ใช้คำว่า "บาปด้าน 1 / ด้าน 2 / ด้าน 3" ซ้ำๆ ตลอดคลิป โดยไม่เคยนิยามให้ชัดในคลิปนี้
  - จากบริบทที่พอจับได้: "ด้าน 1" เป็นเรื่องหนักที่สุด อาจารย์บอกว่า "แรงเลย" และเชื่อมโยงกับเรื่องความเชื่อ (เช่น การไม่เชื่อว่าอัลลอฮ์อยู่เบื้องบน อาจารย์บอกว่า "จะมาด้วยด้าน 1")
  - "ด้าน 2" เป็นเรื่องแนวทาง/ความเชื่อที่รองลงมา และอาจารย์บอกว่าคนยุคนี้ที่ผิดพลาดเรื่องอัลลอฮ์อยู่เบื้องบน "ให้เป็นข้อ 2 ไปก่อน เพราะความมึนมันเยอะ"
  - "ด้าน 3" คือบาปการปฏิบัติทั่วไป อาจารย์ยกตัวอย่างว่า "โต้คนกินเหล้า คนกินน้ำใบกระท่อม" และแยกว่า "บาปใหญ่ บาปเล็ก ก็ว่าไป"
  - หมายเหตุ: ซับเพี้ยนมาก (เขียนสลับกันเป็น "บาปดัน/บาปด่าน/บาปดำ") การจัดชั้นข้างบนเป็นการอ่านจากบริบท ไม่ใช่คำนิยามที่อาจารย์พูดตรงๆ
- ทัศนะที่เลือก: -
- หลักฐาน: -
- อุปมา/ตัวอย่าง: -
- ศัพท์: ด้าน 1 = บาปเรื่องความเชื่อระดับหนัก ; ด้าน 2 = ความผิดพลาดเรื่องแนวทาง/ความเชื่อระดับรอง ; ด้าน 3 = บาปการปฏิบัติ (เหล้า ซินา ใบกระท่อม)
- ช่วง: [008:06], [011:07], [017:10]

### C07 · อันตรายของช่วงซบเซาสำหรับนักเรียกร้อง: การ "เปลี่ยนสูตร"
- หมวด: กลุ่มหลงผิด / ผลของศรัทธาต่อชีวิต
- ระดับ: เสริม — เป็นบทเรียนสำหรับคนทำงานดะอฺวะฮ์ ไม่ใช่หลักศรัทธาโดยตรง แต่อาจารย์ใช้เวลากับมันมาก
- สาระ:
  - อาจารย์เล่าภาพคนที่เรียกร้องสุนนะฮ์มา 20 ปี คนตอบรับน้อยมาก
  - พอเบื่อหน่ายเข้ามา เขาก็คิดว่า "ไม่ไหวแล้ว วิธีนี้ไม่เวิร์ค" แล้วเปลี่ยนวิธี
  - อาจารย์เรียกสิ่งนี้ว่า "เปลี่ยนสูตร" และบอกว่ามันเป็นผลมาจากช่วงซบเซาโดยตรง ไม่ใช่จากการค้นพบความจริงใหม่
  - พอเปลี่ยนวิธีผิด มันจะต่อยอดไปสู่ความผิดอื่นตามมาเรื่อยๆ

### C32 · คัมภีร์หลัก 5 เล่มที่ต้องศรัทธา (ที่อัลกุรอานระบุชื่อ)
- หมวด: คัมภีร์
- ระดับ: แก่น — เป็นแกนของหลักศรัทธาข้อที่ว่าด้วยคัมภีร์ มุสลิมใหม่ต้องรู้ชื่อและว่าเล่มไหนของนบีใคร
- สาระ:
  - อาจารย์ทบทวนว่าเราต้องศรัทธาต่อคัมภีร์ของอัลลอฮ์ 5 หรือ 6 เล่ม แล้วแต่วิธีนับ แต่เขาให้น้ำหนักที่ 5
  - 1) صุฮุฟ (คัมภีร์แผ่น) ของนบีอิบรอฮีม
  - 2) อัตเตารอต ประทานแก่นบีมูซา
  - 3) อัซซะบูร ประทานแก่นบีดาวูด
  - 4) อัลอินญีล ประทานแก่นบีอีซา (พระเยซู)
  - 5) อัลกุรอาน ประทานแก่นบีมุฮัมมัด
  - อาจารย์เน้นว่านี่คือคัมภีร์ที่อัลกุรอานเอ่ยชื่อไว้โดยตรง
- ทัศนะที่เลือก: อาจารย์เลือกนับเป็น 5 เล่ม (บอกว่าบางคนนับ 6 แล้วแต่วิธีนับ) โดยไม่ได้ระบุว่าเล่มที่ 6 คืออะไร
- หลักฐาน:

### C41 · เงื่อนไข "มุห์ศอนาต": ต้องเป็นหญิงเรียบร้อย และเป็นยิว/คริสต์จริง

### C57 · อะกีดะฮ์อิสลาม: นบีอีซาเกิดโดยไม่มีพ่อ เป็นมนุษย์ธรรมดา เป็นนบี — เป็นอิจมาอ์

- ระดับ: เสริม — เป็นข้อสรุปเชิงตัวเลขที่หนักแน่น
- สาระ:
  - อาจารย์บอกว่านบีอีซาสืบทอดคัมภีร์ให้แค่ฉบับเดียว
  - แต่ปัจจุบันมีต้นฉบับเป็นร้อยเป็นพัน โดยที่ใช้อยู่ปัจจุบันเขาระบุตัวเลขว่าราว 5,000 ฉบับ
  - ไม่รู้ว่าอันไหนของจริง และไม่มีสายรายงานเลย
  - เขาเปรียบเทียบว่าคัมภีร์ที่อัลลอฮ์ประทานให้นบีของเรา พระองค์ทรงสัญญาว่าจะปกป้องคุ้มครอง แต่คัมภีร์อื่นไม่มีสัญญาว่าจะปกป้อง
- ทัศนะที่เลือก: -
- หลักฐาน:
  - [อายะฮ์] ที่ได้ยิน: "แต่พอคัมภีร์อื่นเรียกว่ามีคุ้มครองใน...รับประทานแก่...ก็เป็นสัญญาไม่สัญญาว่าจะปกป้องคุ้มครอง" (อาจารย์อ้างถึงสัญญาการปกป้องอัลกุรอาน แต่ไม่ระบุซูเราะฮ์/เลขอายะฮ์) · น่าจะเป็น: ไม่ทราบ · ใจความ: อัลลอฮ์ทรงสัญญาปกป้องคุ้มครองอัลกุรอาน แต่ไม่ได้ทรงสัญญาเช่นนั้นกับคัมภีร์ก่อนหน้า

### C78 · กอสเปลบาร์นาบัส กล่าวถึงการมาของนบีมุฮัมมัดโดยระบุชื่อ
- หมวด: คัมภีร์ / นบี-เราะซูล
- ระดับ: เสริม — เป็นข้อมูลที่มุสลิมใหม่มักได้ยินจากคนอื่น ต้องรู้ท่าทีที่ถูกต้อง
- สาระ:
  - อาจารย์บอกว่ามีกอสเปลฉบับบาร์นาบัส ซึ่งอ้างว่าสืบทอดมาจากนบีอีซาเช่นกัน
  - คัมภีร์อินญีลฉบับบาร์นาบัสกล่าวถึงการมาของนบีมุฮัมมัดโดยระบุชื่อชัดเจน
  - แต่คริสเตียนไม่ยอมรับฉบับนี้
  - อาจารย์บอกตรงๆ ว่าเขาเองยังไม่เคยเจอตัวคัมภีร์ฉบับนี้ และไม่ยืนยันว่าจริงหรือไม่จริง
- ทัศนะที่เลือก: อาจารย์ไม่ยืนยันความน่าเชื่อถือของบาร์นาบัส · เขาเล่าเป็นข้อมูล และย้ำว่า "ไม่ไปยืนยันนะ" · ประเด็นที่เขาต้องการชี้คือ คริสเตียนตัดฉบับนี้ออกโดยไม่มีเหตุผลอธิบาย

### C79 · ไบเบิลหนังแกะที่ตุรกี อายุราว 1,500 ปี
- หมวด: คัมภีร์
- ระดับ: เสริม — เป็นข่าวที่มุสลิมมักแชร์กัน อาจารย์ก็ไม่ยืนยัน
- สาระ:
  - อาจารย์เล่าว่ามีไบเบิลอีกเวอร์ชั่นหนึ่งที่พบที่ตุรกีเมื่อปีสองปีก่อน
  - เขียนบนหนังแกะ ตรวจคาร์บอนได้อายุประมาณ 1,500 ปี
  - อาจารย์บอกว่าฉบับนี้ก็พูดถึงชื่อนบีมุฮัมมัด (ตามซับใช้คำว่า "ชื่ออะฮ์มัด") เหมือนกัน
  - เขาย้ำอีกว่ายังไม่เคยเห็นตัวจริง และไม่ยืนยัน
- ทัศนะที่เลือก: อาจารย์ไม่ยืนยันความถูกต้อง เล่าเป็นข้อมูลเท่านั้น
- หลักฐาน:

### C80 · "กอสเปลของภรรยาพระเยซู" — ข่าวล่าสุดที่ทำให้ฝ่ายเขาวุ่นวายกันเอง
- หมวด: คัมภีร์
- ระดับ: ลึกเกิน — เป็นข่าววิชาการเฉพาะทาง
- สาระ:
  - อาจารย์เล่าว่าเขาอ่านข่าวเจอกอสเปลอีกฉบับหนึ่ง (จำไม่ได้ว่าพบที่ไหน)
  - ชื่อที่อาจารย์แปลคือ "พระวรสารของพระชายาพระคริสต์"
  - ในเล่มนี้บอกว่าแมรี่ แม็กดาลีน เป็นภรรยาของพระเยซู และมีลูกด้วยกัน
  - อาจารย์บอกว่าเราไม่รู้ว่าจริงหรือเท็จ และไม่รู้ว่าต้นฉบับเชื่อถือได้ไหม
  - ประเด็นที่เขาต้องการชี้คือ "ในหมู่พวกเขาเองวุ่นวายไปหมด หาข้อทางลงไม่ได้"
- ทัศนะที่เลือก: -
- หลักฐาน:
  - [อื่นๆ] เอกสารที่มีข่าวเรียกกันตามชื่อว่า "พระวรสารของพระชายาพระคริสต์" : อ้างว่าแมรี่ แม็กดาลีนเป็นภรรยาของพระเยซูและมีลูก (อาจารย์ไม่ยืนยัน)

### C81 · การตรวจคาร์บอนไม่ได้แก้ปัญหา — ปลอมได้ และไม่ทดแทนสายรายงาน

  - เขาเทียบว่าของเรามีกฎเกณฑ์ มีเรื่องสายสืบทอด บุคคลที่อยู่ในสายมีชื่อบันทึกไว้หมด

### C82 · Da Vinci Code เอาเนื้อเรื่องมาจากกอสเปลฉบับคอปติก
- หมวด: อื่นๆ (วัฒนธรรมร่วมสมัย)
- ระดับ: เสริม — เชื่อมเรื่องวิชาการเข้ากับสิ่งที่คนทั่วไปเคยได้ยิน
- สาระ:
  - อาจารย์บอกว่านิยาย Da Vinci Code ของแดน บราวน์ ก็สืบเนื้อเรื่องมาจากเรื่องพวกนี้
  - ในนิยายมีท่อนที่พูดถึงการค้นพบกอสเปลฉบับคอปติก
  - นิยายเดินเรื่องว่าแมรี่ แม็กดาลีนเป็นภรรยาของนบีอีซา
  - และว่าสันตะปาปาปกปิดความจริงนี้มาตลอดพันปี ถึงขนาดก่อสงครามครูเสดเพื่อทำลายความจริงนี้
  - อาจารย์บอกว่าเราไม่ต้องไปอ่านนิยาย เพราะเรามีความเชื่อของเราอยู่แล้ว
- ทัศนะที่เลือก: -
- หลักฐาน:
  - [อื่นๆ] นิยาย Da Vinci Code ของแดน บราวน์ : อ้างว่าแมรี่ แม็กดาลีนเป็นภรรยาของพระเยซู และวาติกันปกปิดความจริงนี้ (อาจารย์เล่าเป็นข้อมูล ไม่รับรอง)
- อุปมา/ตัวอย่าง: -

### C83 · หลักสำคัญ: ศรัทธาต่อคัมภีร์เก่า ต้องคู่กับศรัทธาว่ามันถูกบิดเบือนแล้ว
