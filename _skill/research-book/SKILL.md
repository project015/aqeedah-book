# research-book — ค้นคว้า → หนังสือทั้งเล่ม

## หลักคิด
- **แหล่ง 200+ ชั่วโมงเข้า context เดียวไม่ได้** → ทุกขั้นเขียนลงไฟล์ในโปรเจกต์ `books/<slug>/` แล้วขั้นถัดไปอ่านจากไฟล์ ไม่ใช่จากความจำ
- **หนังสือ ≠ ถอดเทป** → เขียนจาก "การ์ดประเด็น" ที่รวมตามหัวข้อแล้ว ไม่เขียนจาก transcript ตรง
- **หลักฐานศาสนาห้ามพลาด** → ตัวบทอัลกุรอาน/หะดีษดึงจากฐานมาตรฐานเท่านั้น (ไม่พิมพ์จากความจำ) ทุกชิ้นต้องผ่าน `evidence/` ก่อนเข้าเล่ม
- **Ponraphat ตรวจ 3 ด่าน**: (ก) รายการประเด็น เก็บ/ตัด (ข) โครงเล่ม (ค) ทีละบท — ห้ามข้ามไปเขียนเล่มเอง
- ทำงานยาวได้โดยไม่ต้องถาม ยกเว้นตรงด่านตรวจ · ตั้ง CronCreate ปลุกรายชั่วโมงอ่าน STATE.md ทำต่อ ถ้าเขาไม่อยู่

## โครงโฟลเดอร์ `books/<slug>/`
```
STATE.md              ข้อตกลง + checklist ขั้นตอน + บันทึกความคืบหน้า (อ่านก่อนทุกครั้ง)
sources/index.json    รายการแหล่ง (id, ชุด, ตอน, ชื่อ, นาที, ลิงก์เอกสาร)
sources/raw/          json3 ซับ + info.json จาก yt-dlp
sources/transcripts/  <id>.txt ย่อหน้าละ ~1 นาที [mmm:ss]
sources/docs/         เอกสารประกอบ (.pdf + .md ที่ดึงข้อความ)
scripts/              build_transcripts.py · fetch_docs.py · extract_pdf_text.py · CARD_FORMAT.md
cards/<id>.md         การ์ดประเด็นต่อคลิป (สกัดโดย subagent 1 คลิป/ตัว)
topics/<หัวข้อ>.md    การ์ดรวมตามหัวข้อ + นับความถี่
evidence/             quran/ (alquran.cloud uthmani + th) · hadith/ · evidence.md (ทะเบียนหลักฐานที่ตรวจแล้ว)
outline.md            โครงเล่ม (ด่าน ข)
chapters/             ทีละบท (ด่าน ค)
build/                ebook ที่จัดหน้าแล้ว
```

## ขั้นตอน
1. **สำรวจ** `yt-dlp --flat-playlist -J` → นับคลิป/ชั่วโมง รายงาน Ponraphat ก่อน (เขาต้องเคาะขอบเขต ผู้อ่าน ศัพท์ ความยาว รูปแบบ)
2. **ดึงซับ** `yt-dlp --write-auto-sub --sub-lang th-orig --sub-format json3 --skip-download --write-info-json -o "sources/raw/%(id)s"` ทั้งเพลย์ลิสต์ (114 คลิปใช้ ~10 นาที) → `build_transcripts.py`
   - NotebookLM ไม่ใช่ตัวถอด (มันดึงซับ YouTube เหมือนกัน) · whisper large-v3 บน CPU ≈ ช้ากว่า realtime ใช้เฉพาะเทียบคุณภาพหรือคลิปที่ไม่มีซับ
   - เสียง: `yt-dlp -f bestaudio` (ถ้า 403 ให้ `pip install -U yt-dlp`)
3. **เอกสารประกอบ** จาก description: `https://drive.usercontent.google.com/download?id=<ID>&export=download&confirm=t` (ลิงก์ uc?export ธรรมดาได้ HTML) → PyMuPDF ดึงข้อความ หน้าไหนรูปล้วนจดไว้
4. **สกัดการ์ด** subagent general-purpose 1 คลิป/ตัว อ่าน CARD_FORMAT.md + transcript ทั้งไฟล์ (+ เอกสารประกอบถ้ามี) → `cards/<id>.md` · รัน 4 ตัวขนานต่อเทิร์น · ติดตามใน `cards/_progress.json` · ระดับ แก่น/เสริม/ลึกเกิน คือหัวใจ
5. **รวมตามหัวข้อ** สคริปต์อ่านการ์ดทั้งหมด จัดกลุ่มตามหมวด → `topics/` (ประเด็นที่อาจารย์ย้ำหลายคลิป = สัญญาณว่าเป็นแก่น)
6. **ตรวจหลักฐาน** ดึงทุกอายะฮ์/หะดีษจากการ์ดระดับ แก่น/เสริม → เทียบตัวบทกับฐาน → หาที่มา/สถานะหะดีษ (sunnah.com, dorar.net) → `evidence/evidence.md` หาไม่เจอ = ไม่เข้าเล่ม
7. **ด่าน ก** รายงานรายการประเด็น เก็บ/ตัด พร้อมเหตุผล → รอ Ponraphat
8. **ด่าน ข** โครงเล่ม → รอ · 9. **ด่าน ค** เขียนทีละบท จากการ์ด+evidence เท่านั้น · 10. จัดหน้า ebook (HTML → PDF ด้วย Chromium, ฟอนต์ไทย, แผนภาพ/กล่อง/ไทม์ไลน์ · เลขสากล · รูปแบบอ้างซูเราะฮ์ `ซูเราะฮ์X (n) : m`)
