- ห้ามกลืนหลักฐานเข้าไปในช่อง "สาระ" แล้วเขียนว่า "หลักฐาน: -"
- คลิป 1 ชั่วโมงปกติต้องได้หลักฐานอย่างน้อย 15 รายการ ถ้าได้ต่ำกว่านั้นให้อ่านซ้ำ

กฎที่คนทำก่อนหน้ามักพลาด ระวังให้มาก:
1. **ห้ามยุบหลายประเด็นเป็นการ์ดเดียว** เช่น "ตัวหะดีษสอบสวนในหลุมศพ" / "ฉากในหลุมศพ" / "คำถามข้อ 1" / "ผลของการสอบ" = 4 การ์ดแยกกัน · ถ้าช่อง "สาระ" ยาวเกิน 8 บรรทัด แปลว่าต้องแยก
2. **เรื่องนอกหัวข้อศรัทธาก็ต้องทำการ์ด** เช่นอาจารย์แวะพูดเรื่องฟิกฮ์ วิจารณ์กลุ่มอื่น เล่าเรื่องสังคม **ห้ามโยนไปอยู่ "ไม่ทำการ์ด"** ให้ทำการ์ดแล้วติดป้าย "ลึกเกิน" หรือ "เสริม" แทน · ส่วน "ไม่ทำการ์ด" ใช้เฉพาะ ทักทาย ปิดรายการ โฆษณาหนังสือ บริหารห้องเรียน เท่านั้น
3. **ทัศนะที่อาจารย์เลือกในเรื่องที่มีคนเห็นต่าง ต้องมีการ์ดของตัวเอง** พร้อมระบุว่าเขาพูดถึงฝ่ายตรงข้ามว่าอย่างไร
4. **อุปมาและตัวอย่างชีวิตจริงแต่ละอัน แยกการ์ด** ถ้าใช้อธิบายคนละประเด็น (อุปมาคือของมีค่าที่สุดสำหรับเขียนหนังสือให้มุสลิมใหม่เข้าใจ)
